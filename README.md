# LofaMobile

Учебная игра для детей 4-16 лет. Ребёнок раскладывает команды на поле и смотрит, как герой их выполняет: сначала просто «вправо, вправо, вниз», позже — прыжки, повороты и циклы. Мальчики строят штаб, девочки готовят угощение. Программирование здесь получается освоить между делом.

## Запуск

Нужна только Go:

```
go build -o server.exe ./cmd/server
server.exe
```

На Windows можно просто открыть `start.bat`. После запуска — http://localhost:8080.

## Тесты

```
go test ./...
```

Фронтенд живёт в `static/` и не требует сборки: изменил JS или CSS — обновил страницу и увидел результат.

## Настройки

Скопируйте `.env.example` в `.env` и задайте свой `JWT_SECRET`. Если переменную не задать, сервер сгенерирует случайный секрет на один запуск, и после перезапуска старые токены перестанут действовать. В production без `JWT_SECRET` сервер не стартует.

## Ещё немного

- Интерфейс: русский, английский, испанский, таджикский, узбекский, бурятский.
- Админка: `go run ./ADMIN/main.go`, затем http://localhost:8082. Только для локального использования, без доступа извне.
- Данные хранятся в SQLite, файл базы создаётся автоматически и в репозиторий не попадает.
