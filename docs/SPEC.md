# ЛОФА - Логика и Фантазия

## 1. Overview

**Название:** ЛОФА (Логика и Фантазия)  
**Тип:** PWA + Backend мобильная игра  
**Версия:** v0.4.0  
**Целевая аудитория:** Дети 6-14 лет  
**Цель:** Плавное обучение программированию через игру

## 2. Функционал

### 2.1 Регистрация/Авторизация
- Номер телефона (уникальный)
- Псевдоним (ник)
- Имя (опционально)
- Пароль
- Пол: boy (мальчик) / girl (девочка)
- Возраст (опционально)
- Язык интерфейса (ru, en, es, tg, uz)

### 2.2 Игровые уровни

**Базовые команды (уровни 1-10):**
- `up` - вверх на 1 клетку
- `down` - вниз на 1 клетку
- `left` - влево на 1 клетку
- `right` - вправо на 1 клетку
- `jump` - прыжок через 1-2 клетки
- `turn` - разворот на 180°

**Дополнительные команды (сложность):**
- Уровни сложности 1: только basic движения
- Уровни сложности 2: + прыжки
- Уровни сложности 3: + развороты

### 2.3 Система прогресса
- Звезды (1-3) за оптимальность решения
- Очки за прохождение уровней (100 × звезды)
- Таблица лидеров (общая и по полу)
- Система достижений

### 2.4 Темизация
- **Мальчик (boy):** Синяя цветовая схема, персонаж "Строитель" (🔨)
- **Девочка (girl):** Розовая цветовая схема, персонаж "Кулинар" (🍳)
- Предметы: кристалл (💎) / сердечко (💖)

### 2.5 Локализация
Поддерживаемые языки:
- 🇷🇺 Русский (ru)
- 🇬🇧 English (en)
- 🇪🇸 Español (es)
- 🇹🇯 Тоҷикӣ (tg)
- 🇺🇿 O'zbekcha (uz)

## 3. Technical Stack

### Backend (Go)
- **API:** HTTP (REST) + WebSocket для realtime
- **БД:** SQLite (modernc.org/sqlite)
- **Аутентификация:** JWT токены (с поддержкой JWT_SECRET env)
- **Порт:** 8080 (или PORT env)

### Frontend (PWA)
- **Технологии:** HTML5, CSS3, JavaScript (ES6+)
- **Структура:** Модульная (theme, localization, game, auth и др.)
- **PWA:** manifest.json

## 4. Database Schema

```

### Achievements

id, user_id, achievement_type, earned_at
```

### Leaderboard
```
user_id, total_score, username, gender, updated_at
```

## 5. API Endpoints

### Auth
- `POST /api/auth/register` - регистрация
- `POST /api/auth/login` - вход
- `GET /api/auth/me` - текущий пользователь
- `POST /api/auth/profile` - обновить профиль

### Game
- `GET /api/levels` - список уровней
- `GET /api/levels/:id` - данные уровня
- `POST /api/levels/:id/complete` - завершение уровня
- `GET /api/progress` - прогресс игрока

### Social
- `GET /api/leaderboard` - таблица лидеров (?gender=all|m|f)
- `GET /api/achievements` - достижения игрока
- `POST /api/achievements` - сохранить достижение
- `WS /ws` - realtime обновления (score updates)

## 6. Уровни

### Глава 1: Знакомство и основы (уровни 1-10)
Тема: Кулинарное приключение (девочки) / Строительство штаба (мальчики)

### Глава 2: Циклы и условия (уровни 11-20)
Тема: Продвинутые испытания с циклами

### Структура уровня
- Grid (сетка): 0=пусто, 1=стена, 2=старт, 3=финиш, 4=предмет
- Player: {x, y, direction}
- Par: оптимальное количество ходов
- Available Commands: доступные команды

## 7. Сценарии

Каждый уровень имеет сценарий:
- Intro: вводная история
- Task: описание задачи
- Gender-specific: разные сценарии для мальчиков и девочек
