# ЛОФА - Логика и Фантазия - Game Design Document

## 1. Vision

**Название:** ЛОФА (Логика и Фантазия)  
**Слоган:** "Учись программировать играя!"  
**Жанр:** Обучающая головоломка  
**Платформа:** PWA (Android + iOS)

## 2. Целевая аудитория

- **Возраст:** 6-14 лет
- **Пол:** Все (с адаптацией под M/F/Other)
- **Опыт:** Без предварительного опыта в программировании

## 3. Core Gameplay Loop

```
Уровень → Код → Выполнение → Результат → Звезды → Следующий уровень
```

**Тип игрока:**
1. Смотрит на карту уровня
2. Перетаскивает блоки команд в область кода
3. Нажимает "Выполнить"
4. Смотрит анимацию персонажа
5. Получает результат (звезды)

## 4. Модульная архитектура

### JavaScript модули
- **theme.js** - Темизация (мальчик/девочка)
- **localization.js** - Локализация (заготовка)
- **levelsManager.js** - Управление уровнями
- **achievementsManager.js** - Достижения
- **gameLogic.js** - Логика прохождения
- **soundsManager.js** - Звуки (заготовка)
- **leaderboardManager.js** - Таблица лидеров

### Go backend
- REST API для авторизации, игры, социальных функций
- SQLite база данных
- WebSocket для realtime обновлений

## 5. Commands (Команды)

### Базовые (уровни 1-10)

| Команда | Описание | Иконка |
|---------|----------|--------|
| `forward` | Переместиться вперед на 1 клетку | ⬆️ |
| `backward` | Переместиться назад на 1 клетку | ⬇️ |
| `left` | Переместиться влево | ⬅️ |
| `right` | Переместиться вправо | ➡️ |
| `collect` | Взять предмет | 💎 |
| `drop` | Положить предмет | 📦 |

### Циклы (уровни 11-20)

| Команда | Описание |
|---------|----------|
| `repeat N` | Повторить N раз |

## 6. Система уровней

### Глава 1: Знакомство и основы (1-10)
- Постепенное введение команд
- Простые головоломки
- К концу: комбинирование 4-5 команд

### Глава 2: Познание цикла (11-20)
- Введение циклов
- Уровни 11-13: Простые циклы
- Уровни 14-16: Циклы + условия
- Уровни 17-19: Вложенные циклы
- Уровень 20: Финальный босс

### Блокировка уровней
- Уровень 1: открыт всегда
- Уровень N: доступен только если пройден уровень N-1
- Замок 🔒 на не пройденных уровнях

## 7. Scoring System

### Звезды за уровень (1-3)
- ⭐ -level completed
- ⭐⭐ -level completed within par
- ⭐⭐⭐ -level completed within par - no mistakes

### Очки
- За звезду: 100/200/300 очков
- Бонус за уровень: +50 за каждые 5 уровней

### Leaderboard
- Глобальный (все игроки)
- По полу (отдельный для M/F)

## 8. Визуальный стиль (WoW Kids)

### Тема: Мальчик (синие тона)
- **Персонаж:** Рыцарь ⚔️
- **Цвета:** Синий, золотой, коричневый
- **Предметы:** Кристаллы 💎
- **Фон:** Темно-синий градиент

### Тема: Девочка (розовые тона)
- **Персонаж:** Волшебница ✨
- **Цвета:** Розовый, фиолетовый, золотой
- **Предметы:** Сердечки 💖
- **Фон:** Темно-розовый градиент

### До логина
- Бежево-коричневый фон
- Нейтральные цвета

## 9. Достижения

| ID | Название | Условие |
|----|----------|---------|
| first_login | Первое посещение | Вход в игру |
| first_level | Первые шаги | Прохождение 1 уровня |
| level_5 | Начинающий герой | Прохождение 5 уровней |
| level_10 | Опытный герой | Прохождение 10 уровней |
| chapter_1_complete | Первая глава пройдена | Прохождение главы 1 |
| chapter_2_complete | Цикломастер | Прохождение главы 2 |
| all_levels | Мастер программирования | Прохождение всех 20 уровней |

## 10. User Progression

### Регистрация
1. Вход (логин) или создание аккаунта
2. Выбор персонажа (Рыцарь/Волшебница/Лучник)
3. Ввод данных (телефон, ник, имя, возраст, пароль)
4. Применение темы

### Мотивация
- Прогресс-бар уровней
- Достижения
- Таблица лидеров
- Звезды за уровни

## 11. Технологии

### Frontend
- HTML5, CSS3, JavaScript (ES6+)
- PWA (Progressive Web App)
- Модульная структура

### Backend
- Go (Golang)
- SQLite база данных
- REST API + WebSocket
- JWT авторизация

## 12. Monetization (Future)

- Бесплатная версия: 20 уровней
- Платные миры: 100+ уровней
- Без рекламы
- Без in-app purchases в первой версии
